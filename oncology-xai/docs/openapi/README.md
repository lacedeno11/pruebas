# OpenAPI Specifications

This directory contains the OpenAPI specifications for all DERCAS-ONCO-XAI V1 services.

> **Note**: OpenAPI specifications will be generated automatically in T14 - Documentation task.

## Service APIs

- `api-gateway.json` - API Gateway OpenAPI specification
- `case-service.json` - Case Service OpenAPI specification  
- `image-service.json` - Image Service OpenAPI specification
- `inference-service.json` - Inference Service OpenAPI specification
- `ehr-service.json` - EHR Service OpenAPI specification
- `graph-service.json` - Graph Service OpenAPI specification
- `ontology-admin-service.json` - Ontology Admin Service OpenAPI specification
- `audit-service.json` - Audit Service OpenAPI specification

## Usage

These specifications can be used for:
- API documentation generation
- Client SDK generation
- Contract testing
- API validation
